## What I do

I design and build data platforms, distributed systems and tooling (SDKs, APIs and Contracts) plus open source. Mostly in JVM (Scala, Java, Kotlin) and Python. Increasingly in Rust & Go. Write technical articles and sometimes speak in events/conferences.

- Resume: [vitthalmirji.com/resume](https://vitthalmirji.com/resume)

- A few things I ship:
  - [flowforge](https://github.com/vim89/flowforge) - Type-safe Scala data engineering toolkit with compile-time contract validation. Prevents schema drift before deploy
  - [llm4s](https://github.com/vim89/llm4s) - reliable LLM apps in Scala
  - [compile-time-data-contracts](https://github.com/vim89/compile-time-data-contracts) - schema checks that break the build, not prod
  - [abortable-bytes](https://github.com/vim89/abortable-bytes) - cancel-safe cloud uploads (scala/kyo POC)
  - [toon4s](https://github.com/vim89/toon4s) - token-friendly JSON for LLM work
  - [datapipelines-essentials-python](https://github.com/vim89/datapipelines-essentials-python) - practical helpers for ETL in Python/Spark
  - I also contribute to:
    - [cask](https://github.com/com-lihaoyi/cask)
    - [scalasql](https://github.com/com-lihaoyi/scalasql)

- Ask me about: data engineering, data contracts, Scala, Functional programming, Spark/Databricks, GCP BigQuery, Kafka/Flink, and clean APIs.

- LinkedIn: [linkedin.com/in/vitthal10](https://www.linkedin.com/in/vitthal10/)
